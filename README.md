# AI-Powered Student Support System

## Overview

This project is a functional AI-driven Student Support System designed to assess academic and emotional risk indicators and automatically assign appropriate support resources.

The system evaluates student inputs such as stress level, academic struggle, assignment backlog, and follow-up requests to determine risk level and route students to counselors and tutors accordingly.

This project demonstrates applied AI logic, workflow automation, and structured QA validation in a real-world student services context.

---

## Problem Statement

Educational institutions often struggle to identify and prioritize students who need immediate academic or emotional support. Manual triage systems can be slow, inconsistent, and resource-intensive.

This system simulates an intelligent triage process that:

- Identifies high-risk students

- Assigns appropriate counselors

- Balances counselor workload

- Schedules appointments dynamically

- Displays a real-time dashboard for visibility
